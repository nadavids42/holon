# 0001: Start with one Python package and a minimal persistent loop

Status: accepted, 2026-10-24.

Keep reusable implementation in `src/holon`, checks in `tests`, and research
protocols in `experiments`. Keep the living charter at the repository root.
Begin with standard-library Python, SQLite, deterministic evidence-presence
rules, and a CLI. Add one model after the durable loop works; undertake comparative
evaluation after that. Additional modules and services require a concrete need.
Runtime databases and generated runs are ignored by Git and require separate backups.
